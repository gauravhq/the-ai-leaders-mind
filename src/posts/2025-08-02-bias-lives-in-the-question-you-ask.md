---
title: "Bias Lives in the Question You Ask"
date: 2025-08-02
pageDescription: "A leading prompt returns a leading answer. The slant starts before the model speaks."
---
We talk about bias in the model's answers, but a lot of it enters earlier, in the question. How you ask shapes what you get, and a slanted question produces a slanted answer that then looks like independent confirmation.

Ask a model to explain why a plan will work, and it explains why it will work. Ask which risks the plan faces, and you get a different picture entirely, from the same tool, in the same minute. The machine is not deciding to agree with you; it is answering exactly what you asked, and you asked in a way that pointed at the answer you wanted.

This is easy to do without noticing. The question feels neutral because it matches what you already think.

So watch your own prompts. Would a skeptic have asked it this way? Try asking the opposite version and see how much the answer moves. If a small change in the question flips the result, the result was never solid. The bias did not start with the machine. It started with you, one question earlier.
