---
title: "Confirmation Bias: The Machine That Agrees With You"
date: 2026-03-01
pageDescription: "A model that only ever agrees with you is not a colleague. It is an echo."
---
Ask a capable model a leading question and it will often hand you back a well-argued version of what you already believed. It is agreeable by design. That makes it a powerful mirror and a dangerous one.

Confirmation bias was already the most expensive habit in any leadership team. We look for what fits, and we file away what does not. A tool that can generate fluent support for any position on demand pours fuel on that fire.

The tell is how the answer feels. Real analysis often lands with a little friction, something you did not want to hear. An answer that feels purely satisfying deserves a second look, not because it is wrong, but because comfort is not evidence.

So use the machine against yourself. Ask it to make the strongest case for the opposite of what you want. Ask what would have to be true for your plan to fail. A model that only ever agrees with you is not a colleague. It is an echo, and echoes have never saved anyone from a bad call.
